## 🔧 TAREAS TÉCNICAS PARA BRIGITTE (Por hacer en código)

### Si aún no está hecho:
1. **Meta tags dinámicos:**
   - Cambiar `<title>` por keyword + marca (ej: "Ropa de Hombre Mayorista Argentina | Mirrow")
   - Meta description keyword-rich pero natural

2. **Estructura de headings:**
   - H1 solo uno por página, con keyword
   - H2/H3 jerárquica con variaciones de keyword

3. **Structured Data:**
   ```html
   <!-- LocalBusiness Schema -->
   <script type="application/ld+json">
   {
     "@context": "https://schema.org",
     "@type": "LocalBusiness",
     "name": "Mirrow",
     "description": "Distribuidor de ropa de hombre mayorista en Argentina",
     "url": "https://grupomirrow.com.ar",
     "areaServed": "AR",
     "telephone": "+5491160192099",
     "address": {
       "@type": "PostalAddress",
       "streetAddress": "...",
       "addressLocality": "Buenos Aires",
       "addressCountry": "AR"
     }
   }
   </script>
   ```

4. **Sitemap.xml:**
   - Verificar que esté en `robots.txt`
   - Incluir todas las URLs principales
   - Incluir `/envios/*` (páginas por provincia)

5. **robots.txt:**
   - Verificar que no tenga `Disallow: /`
   - Permitir crawling de assets (CSS, JS)

6. **Core Web Vitals:**
   - Revisar LCP (Largest Contentful Paint) - debe ser <2.5s
   - CLS (Cumulative Layout Shift) - <0.1
   - FID (First Input Delay) - <100ms
   - Herramienta: Chrome DevTools → Lighthouse
